    // SYSTEM SPECS

    How to find your specs

    1. Press Win + R, type msinfo32 and press Enter. The System Summary shows your OS, processor and installed RAM.
    2. Press Win + R, type dxdiag and press Enter. Open the Display tab for your graphics card and driver version.
    3. Alternatively, go to Settings → System → About.
    1. Click the Apple menu → About This Mac. The Overview tab shows your macOS version, chip and memory.
    2. Click System Report… for full details, including graphics cards under Graphics / Displays.
    3. For a quick summary, open Terminal and run system_profiler SPHardwareDataType.

    Open a terminal and run these commands, then copy the output:

    uname -a
lsb_release -a
lscpu | head -20
free -h
lspci | grep -i -E 'vga|3d|display'
glxinfo -B | head -20

    Or run neofetch / fastfetch if installed and copy the summary.

    This fills the system specs box with a handy layout.
